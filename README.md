WHAT IF Frontend v4
====================
This version turns the What If experience into a true long-form reader.

Files:
- index.html: homepage + immersive scenario explorer
- scenario.html: dedicated readable scenario page
- styles.css: responsive light/dark design
- script.js: scenario data, navigation, theme, reader rendering

How to use:
1. Unzip.
2. Open index.html in a browser.
3. Choose a scenario under "What if it happened differently?"
4. Click "Read full timeline →".
5. Each scenario has its own URL, e.g. scenario.html?id=neymar

Note:
The scenario copy is prototype/illustrative content. For production, add verified primary sources and editorial review to the FACT layer.
